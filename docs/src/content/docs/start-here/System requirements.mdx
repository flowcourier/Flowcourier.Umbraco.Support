## Supported Umbraco versions

:::caution[Legacy package — Umbraco 10–13]
This is the documentation of the legacy **Google Analytics for Umbraco** package (`Flowcourier.Umbraco.Analytics`), which is deprecated: its 13.x releases stay available for sites on Umbraco 13, nothing new is published under that id. On Umbraco 17.5+ use [Flowcourier Analytics](/docs/analytics/start-here/get-started/) with the [Google Analytics provider](/docs/analytics/guides/google-analytics/); the steps are on the [migration page](/docs/analytics/guides/migrating-from-the-legacy-package/).
:::

The extension is tested on:

- **Umbraco 10.x**
- **Umbraco 11.x**
- **Umbraco 12.x**
- **Umbraco 13.x**

Umbraco 14–16 are not supported by this package. For Umbraco 17.5+ use its successor, the [Google Analytics provider](/docs/analytics/guides/google-analytics/) for Flowcourier Analytics — see the [FAQ](/docs/faq/#does-the-extension-support-umbraco-14-17).
