# System requirements

| Requirement | Version |
|-------------|---------|
| Umbraco | 17.5+ (LTS) |
| .NET | 10+ |
| **Matomo** provider | Matomo 4.x or 5.x, self-hosted or Matomo Cloud, reachable over HTTPS from the Umbraco server; a `token_auth` for a user with *view* access to the website |
| **Google Analytics** provider | A GA4 property; a Google Cloud service account with the Google Analytics Data API enabled, added as a *Viewer* on the property |

The packages have **no AI dependency** and create no database tables by default: they read reports from the provider's API on demand and cache them briefly in memory. Two optional features add tables when switched on — `FcAnalyticsIndexStatus` for Search Console index tracking, and the three `FcAiVisibility*` tables for AI Visibility (`Flowcourier:Analytics:AI:Visibility:Enabled`).

## Packages

| Package | Contents |
|---------|----------|
| [`Flowcourier.Umbraco.Matomo`](https://www.nuget.org/packages/Flowcourier.Umbraco.Matomo/) | The Matomo provider: reads your Matomo's Reporting API (also visitor journeys) |
| [`Flowcourier.Umbraco.GoogleAnalytics`](https://www.nuget.org/packages/Flowcourier.Umbraco.GoogleAnalytics/) | The Google Analytics provider: reads your GA4 property's Data API — see [Google Analytics](/docs/analytics/guides/google-analytics/) |
| [`Flowcourier.Umbraco.Analytics.Core`](https://www.nuget.org/packages/Flowcourier.Umbraco.Analytics.Core/) | Installed automatically with a provider: the Analytics section, the document tab, PageSpeed Insights, Search Console, the live badge |
| [`Flowcourier.Umbraco.Analytics.AI`](https://www.nuget.org/packages/Flowcourier.Umbraco.Analytics.AI/) | Optional: the [Copilot tools](/docs/analytics/guides/copilot/) and [AI Visibility](/docs/analytics/guides/ai-visibility/); needs the Umbraco AI runtime |
| `Flowcourier.Umbraco.Foundation` | Installed automatically as a dependency: the Flowcourier group in the Settings section, the shared chart element, licensing |

Install **one** provider. The package version signals the minimum supported Umbraco release: `17.5.x` requires Umbraco 17.5 or later. Core, the providers and Analytics.AI are released together with equal versions.

## Notes

- **Outbound access**: with the Matomo provider the Umbraco server calls `https://<your-matomo>/index.php` with POST requests; with the Google Analytics provider it calls `analyticsdata.googleapis.com` and `analyticsadmin.googleapis.com`. The Google features (Search Console, PageSpeed, and the Google Analytics provider's token) also reach `oauth2.googleapis.com`, `www.googleapis.com` and `searchconsole.googleapis.com`. Allow those hosts through any egress firewall.
- **Tracked URLs**: the document tab looks a page up by its tracked host and route. Matomo stores absolute URLs; GA4 stores host and path separately. In both cases the tracked host must match — see [Configuration](/docs/analytics/guides/configuration/#siteurl-and-multi-site-installs) for staging hosts and multi-site installs.
- **Unique visitors over a range** (Matomo) are only available when your host enables unique-visitor processing for custom ranges (`enable_processing_unique_visitors_range`). GA4 always reports users.
- **Segments** (Matomo): the page-scoped breakdowns on the document tab use a Matomo segment processed on the fly. On a large self-hosted Matomo with browser-triggered archiving disabled they can come back empty.
- **What GA4 cannot answer**: visitor journeys, individual realtime visits, exit pages and a page's live count — the [Google Analytics guide](/docs/analytics/guides/google-analytics/#what-ga4-cannot-answer) lists them.
- Backoffice assets are served from `App_Plugins` (`fc-analytics`, `fc-foundation`) and built for the Umbraco Bellissima backoffice.

## Free versus Pro

| | Free | Analytics Pro |
|---|---|---|
| The Analytics section, every dashboard, the document tab, findings, both providers, PageSpeed Insights, Search Console, the Copilot tools | ✓ | ✓ |
| [AI Visibility](/docs/analytics/guides/ai-visibility/) — the prompt set sampled through your AI profiles, citation tracking, the dashboard and the sub-tab | — | ✓ |

Everything but AI Visibility is free to use, including commercially, under the Flowcourier License 1.0 — no license key, no domain restrictions, whichever provider you install. AI Visibility takes an **Analytics Pro** key at `Flowcourier:Licenses:AnalyticsPro`:

- Keys are bound to your **domains**. Local development hosts (`localhost`, `127.0.0.1`, `*.local`) always work, so one key covers production and every developer machine.
- Keys are bound to the **Umbraco LTS cycle** they were purchased for (for example Umbraco 17 through 20). Upgrading to the next LTS requires a new license — typically part of your upgrade project.
- Your site never breaks over licensing: without a key the AI Visibility surfaces show a banner over whatever data exists and the sampling stays idle; everything else is unaffected.

Keys are obtained by [contacting Flowcourier](https://flowcourier.com/).
